So... what is HTML?

HTML stands for HyperText Markup Language. Basically, it tells your browser what exists on a webpage. Text? HTML. Image? HTML. Button? HTML. Headings? Yep.

01 / STRUCTURE

🧱 The Skeleton

HTML creates the basic structure of your website. Think of it as the skeleton before CSS makes everything look insane.

02 / TAGS

🏷️ Tags

Tags tell the browser what something is. Heading, paragraph, image, link, button — each has its own tag.

03 / BROWSER

🌐 Browser

Your browser reads HTML and turns those tags into the webpage you're looking at right now.

Meet the tags.

HTML is basically a language made from tags. Here's the cheat sheet.

<h1>

Headings

The big boys. Use headings to create titles and sections.

<p>

Paragraph

Used whenever you want normal text on your page.

<a>

Links

Send users somewhere else using clickable links.

<img>

Images

Put images directly onto your webpage.

<button>

Buttons

Interactive-looking buttons start with HTML.

<ul>

Lists

Create ordered and unordered lists easily.

Okay... show me code.

This is literally enough to create your first HTML page. No framework. No complicated setup. Just HTML.

index.html
<!-- your first website -->

<!DOCTYPE html>

<html>

<body>

    <h1>
        Hello, Internet.
    </h1>

    <p>
        I just made a website.
    </p>

    <button>
        Click me
    </button>

</body>

</html>
> HTML compiled successfully
> Website.exe has entered the chat 💀

Tags have stats.

They're called attributes. They give HTML elements extra information.

attributes.html
<a
    href="https://example.com"
>

    Visit Website

</a>


<img
    src="image.jpg"
    alt="Cool image"
>
💡 Remember: An attribute gives extra information to an HTML element.
